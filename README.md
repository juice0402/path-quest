## Projects

## PATH QUEST: current direction

- 積み木で道を作りながら、ぜんまいの騎士がおもちゃの国を旅するローグライト。どこまで遠くへ行けるかを目指す
- 見た目はパステルの積み木。地面はエリアごと（草原→森→湖→雪原→おもちゃの城、各5ステージ。城のあとは2周め）
- 盤面は横5マスの縦長で、騎士について上へスクロールする（ステージが進むと縦7→9→11→13マス）。盤面の上に重ねて出すのは HP・攻撃・守り・金貨・帰還だけ。文字の欄はない
- 盤面の下に積み木の候補4こ（強化で最大6こ）。向きは固定でランダム、回転はなし。上下に進む形が出やすい
- 積み木は道の先（光っているマス）にだけ置ける。置けないマスに置こうとすると、マスと積み木が赤く点滅する。置くと騎士がすぐそこへ進む
- 合わないときは盤面の右下のサイコロで「リロール」：候補を全部山にもどしてまぜ、引き直す（1ステージ3回、強化で+1ずつ最大6回）。戻す・捨てるはない
- タップで選んでマスをタップ、またはドラッグで置く（指の少し上に浮いた積み木の下のマスに置かれる）
- 積み木にはおもちゃの兵隊（へいたい・ラッパ兵・おもちゃの大砲・ブリキのロボ）・金貨・キャンディ・剣・盾がのることがある。通ると効果を受ける。敵には受けるダメージが出る
- 戦闘は敵の手前のマスで、敵の攻撃→騎士の攻撃を、敵がたおれるまでくり返す。被ダメは騎士の頭上、与ダメは敵の頭上に出る
- 負け：HP がゼロになる、積み木がなくなる、道が行き止まりになる、つながる積み木がなくリロールものこっていない
- ステージは毎回自動で作る（通れないもの・ビー玉）。5ステージめは旗の前に「兵隊長」
- ステージをクリアするたびにごほうびを1つえらぶ。冒険が終わると金貨を持ち帰り、強化（体力・剣・盾・積み木・リロール回数・候補の数）に使う
- 公開先はあそびトークのゲーム工房の予定

## Run locally

PATH QUESTのフォルダにある `index.html` をブラウザで開くと試遊できます。進み具合と強化は端末の中（localStorage）にだけ保存します。
