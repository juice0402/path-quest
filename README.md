## PATH QUEST: current direction

- 積み木で道を作りながら、ぜんまいの騎士がおもちゃの国を旅するローグライト。どこまで遠くへ行けるかを目指す
- 見た目はパステルの積み木。地面はエリアごと（草原→森→湖→雪原→おもちゃの城、各5ステージ。城のあとは2周め）
- 盤面は横5マスの縦長で、騎士について上へスクロールする（ステージが進むと縦7→9→11→13マス）。盤面の上に重ねて出すのは HP・攻撃・守り・金貨だけ。文字の欄はない
- 盤面の下の枠に積み木の候補4こ（強化で最大6こ。何こでも同じ大きさ）と、横長の「リロール」「帰還」ボタン。向きは固定でランダム、回転はなし。上下に進む形が出やすい
- 積み木は道の先（光っているマス）にだけ置ける。置けないマスに置こうとすると、マスと積み木が赤く点滅する。置くと騎士がすぐそこへ進む
- 合わないときは「リロール」：候補を全部山にもどしてまぜ、引き直す（1ステージ3回、強化で+1ずつ最大6回）。戻す・捨てるはない
- タップで選んでマスをタップ、またはドラッグで置く（指の少し上に浮いた積み木の下のマスに置かれる）
- 積み木にはおもちゃの兵隊（へいたい・ラッパ兵・おもちゃの大砲・ブリキのロボ）・金貨・キャンディ・剣・盾がのることがある。通ると効果を受ける。敵には受けるダメージが出る
- 戦闘は敵の手前のマスで、敵の攻撃→騎士の攻撃を、敵がたおれるまでくり返す。被ダメは騎士の頭上、与ダメは敵の頭上に出る
- 負け：HP がゼロになる、積み木がなくなる、道が行き止まりになる、つながる積み木がなくリロールものこっていない
- ステージは毎回自動で作る（通れないもの・ビー玉）。5ステージめは旗の前に「兵隊長」
- ステージをクリアするたびにごほうびを1つえらぶ。冒険が終わると金貨を持ち帰り、強化（体力・剣・盾・積み木・リロール回数・候補の数）に使う
- 10段ごとのごほうびは「おもちゃ箱」（ヴァンサバ風・その冒険だけ）：勝手に攻撃するおもちゃ武器5種（紙ひこうき・ぐるぐるコマ・ビー玉ばくだん・ブーメラン・シャボン玉）とお守り8種から3択。同じものはLv5まで育つ。武器3つ・お守り3つまで。武器Lv5＋対になるお守りで、大将の宝箱か次元のゲートで大進化
- スキル12種（道・戦い・お金と回復）。強化画面の「スキル」タブで金貨でおぼえて3つまでセット。冒険中は引き出しから使い、使うと決まったマス数を歩くまで休む。最初は「くるっと回す」だけ持っている
- 次元：50段ごとに「おもちゃの王さま」が門を守る。たおすと先の段から少しずつ次の次元（夕やけ→夜→ゆめ→こおり→虹）に変わり、敵が強く、レアな装備が出るようになる。場所（20段ごと）はそのまま
- 装備は武器・防具・お守り 各16こ（★1〜★4）。★2から上は2つめ以降の次元で見つかる。杖（手持ちの敵に魔法）・ステッキ（まわりのフィールドの敵に魔法）・魔導書（毒）・鏡（はね返し）・ローブ（魔法の範囲）・会心・先制・吸収・十字が出やすくなるお守り など
- フィールドに立っているだけの敵がいる（そのマスには置けない）。魔法・大砲どーん・おかたづけでどかせる
- 十字の積み木は切り札：出にくく、金色の道と星で光る
- 公開先はあそびトークのゲーム工房の予定

## Run locally

PATH QUESTのフォルダにある `index.html` をブラウザで開くと試遊できます。進み具合と強化は端末の中（localStorage）にだけ保存します。
