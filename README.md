## Projects

## PATH QUEST: current direction

- 下の入口から上の階段へ、道を作りながら進むローグライト。何階まで潜れるかを目指す
- 盤面は横5マスの縦長で、勇者について上へスクロールする（階が進むと縦7→9→11→13マス）
- 盤面の下にパネル候補4枚（強化で5枚）。向きは固定でランダム、回転はなし。上下に進むパネルが出やすい
- パネルは道の先（光っているマス）にだけ置ける。置くと勇者がすぐそこへ進む。合わないパネルは「捨てる」（1枚へる）
- タップで選んでマスをタップ、またはドラッグで置く（スマホのタッチ操作が基本）
- パネルには敵・金貨・薬・剣・盾がのることがある。勇者が通ると効果を受ける。敵のパネルには受けるダメージが出る
- 負け：HP がゼロになる、パネルがなくなる、道が行き止まりになる。「ひとつ戻す」は1階3回まで
- 階は毎回自動で作る（岩・宝石）。5階ごとに階段の前に「階のぬし」
- 階を突破するたびにごほうびを1つえらぶ。冒険が終わると金貨を持ち帰り、強化（体力・剣・守り・パネル・戻す回数・候補5枚）に使う
- 公開先はあそびトークのゲーム工房の予定

## Run locally

PATH QUESTのフォルダにある `index.html` をブラウザで開くと試遊できます。進み具合と強化は端末の中（localStorage）にだけ保存します。
