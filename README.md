# Game Workshop

このリポジトリは、PATH QUESTを含む複数のゲームをまとめて開発するためのワークスペースです。

## Projects

- `games/path-quest/` — PATH QUEST（開発中）

## PATH QUEST: current direction

- タッチ操作を中心にした、パネル配置型のグリッドゲーム
- 盤面の下に4つのパネル候補を表示
- プレイヤーは候補を選んで空きマスに配置
- パネルの向きは候補ごとにランダム提示し、回転操作は設けない

## Run locally

PATH QUESTのフォルダにある `index.html` をブラウザで開くと試遊できます。
