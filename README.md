## Projects

- `games/path-quest/` — PATH QUEST（開発中）

## PATH QUEST: current direction

- パネルで入口から階段まで道をつなぎ、ダンジョンを何階まで潜れるかを目指すローグライト
- 盤面の下にパネル候補4枚（強化で5枚）。向きは固定でランダム、回転はなし
- タップで選んでマスをタップ、またはドラッグで置く（スマホのタッチ操作が基本）
- パネルには敵・金貨・薬・剣・盾がのることがある。つながると勇者が道を進み、通ったパネルの効果を受ける
- 負け：HP がゼロになる、またはパネルがなくなって道がつながらない
- 階は毎回自動で作る。階が進むと盤面が広がり（5×5→6×6→7×7）、敵が強くなる。5階ごとに階段の前に「階のぬし」
- 階を突破するたびにごほうびを1つえらぶ。冒険が終わると金貨を持ち帰り、強化（体力・剣・守り・パネル・戻す回数・候補5枚）に使う
- 公開先はあそびトークのゲーム工房の予定

## Run locally

PATH QUESTのフォルダにある `index.html` をブラウザで開くと試遊できます。進み具合と強化は端末の中（localStorage）にだけ保存します。
