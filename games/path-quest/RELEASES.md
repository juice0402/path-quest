# PATH QUEST の版

あそびトークのゲーム工房に出すときの合図。新しい版をいちばん上に足す。

- 見出しは「## v1.2・2026-11-20」の形（版・日付）。その下に変えたことを日本語で短く（1行1つ）
- 版の下の行は、工房のお知らせにそのまま出る（v1.2 から）。「〜しました」の形・絵文字なし・行の字を全部足して120字まで。例：「- 雪原に新しい敵を足しました」「- お店の並びを直しました」
- main にマージされると、GitHub Actions（.github/workflows/release.yml）が、まだタグのない版にタグと Releases を作る
- タグを付けるコミットは、そのマージのコミット。文の最後に「（3c569c3）」のようにコミットを書いた版だけは、そのコミットに付ける
