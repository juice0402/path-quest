# PATH QUEST の版

あそびトークのゲーム工房に出すときの合図。新しい版をいちばん上に足す。

- 見出しは「## v1.1・2026-11-20」の形（版・日付）。その下に変えたことを日本語で短く（1行1つ）
- main にマージされると、GitHub Actions（.github/workflows/release.yml）が、まだタグのない版にタグと Releases を作る
- タグを付けるコミットは、そのマージのコミット。文の最後に「（3c569c3）」のようにコミットを書いた版だけは、そのコミットに付ける

## v1.1・2026-11-05
- はじめての冒険は、騎士くんの上に「上へ」の矢じるしが出る
- 最初の一手は、上にまっすぐの積み木だけ置ける
- はじめはスキルなし（くるっと回すはお店で覚える）
- くるっと回すで、どっちに回るかと回るようすが見える
- 手持ちの積み木をタップすると、のっている敵・装備・金貨などがわかる
- 盤面の家や木・かべ・柵・毒・ビー玉などをタップすると、何かがわかる
